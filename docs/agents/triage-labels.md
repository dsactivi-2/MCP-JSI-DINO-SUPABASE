# Triage oznake

Pet kanonskih uloga Matt Pocock vještina koristi istoimene postojeće Linear
oznake. Dostupnost u timu Activi potvrđena je 2026-09-10.

<!-- markdownlint-disable MD013 -->

| Kanonska uloga | Linear oznaka | Značenje |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Potrebna je početna procjena issuea. |
| `needs-info` | `needs-info` | Nedostaju informacije potrebne za nastavak. |
| `ready-for-agent` | `ready-for-agent` | Issue je dovoljno specificiran za agentski rad; provjeriti blokere. |
| `ready-for-human` | `ready-for-human` | Potrebna je ljudska odluka ili rad. |
| `wontfix` | `wontfix` | Odlučeno je da se issue neće realizirati. |

<!-- markdownlint-enable MD013 -->

Vještine koriste desnu oznaku za odgovarajuću kanonsku ulogu i ponovo koriste
postojeće oznake. Mapiranje ne ograničava druge projektne oznake.
Pripadnost issuea i status toka rada određuje [issue tracker](issue-tracker.md).
