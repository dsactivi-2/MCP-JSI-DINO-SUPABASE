# Conventions

- Use English for code identifiers and comments.
- Use Bosnian/Croatian/Serbian Latin for project documentation unless a deliverable requires another language.
- No code-style, naming, typing, module-layout, or test convention is established yet because the application scaffold has not been created.
- Keep repository-level agent instructions repo-specific; do not duplicate global Codex rules.
- Keep durable architecture decisions in versioned ADRs under `docs/decisions/`.
- Do not add placeholder commands or pretend that absent tests, linters, or type checkers passed.
