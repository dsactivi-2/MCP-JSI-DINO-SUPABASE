# Memory Maintenance

- Keep `mem:core` as the graph root and link focused memories with backticked `mem:` references.
- Store only durable, non-obvious project facts; omit task-local notes, secrets, credentials, customer data, and volatile details.
- Prefer terse invariant bullets over prose.
- Update an existing focused memory instead of duplicating facts.
- Run `serena memories check` after renames or structural changes.
